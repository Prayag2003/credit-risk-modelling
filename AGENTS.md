# Project Instructions

- Keep credit-risk documentation concise, clearly structured, and numbered consistently with the README contents links.
- Explain concepts in plain language and define abbreviations on first use.
- Distinguish the Basel prudential framework from IFRS financial reporting standards; do not describe either as belonging to only one region.
- When documenting loss estimates, define PD, LGD, and EAD and identify simplified formulas as such.
- Add only information relevant to credit risk modelling, and correct factual inaccuracies rather than repeating them.
- Please don't keep any em-dashes.
